# Nexus AI — Enterprise Flutter Web Admin Panel

Production-ready enterprise Flutter Web Admin Panel for managing Nexus AI platform users, RBAC roles, AI models, telemetry analytics, planner tasks, finance metrics, push notifications, cloud storage, and system feature flags.

## 🚀 Running Locally

```bash
# Install dependencies
flutter pub get

# Run on Chrome
flutter run -d chrome
```

## 🧪 Testing & Analysis

```bash
# Static analysis
flutter analyze

# Unit & Widget tests
flutter test
```
